# 🍱 ระบบจัดการร้านอาหารเดลิเวอรี่

ระบบจัดการร้านอาหารสำหรับร้านที่ขายผ่านแอพเดลิเวอรี่ (GrabFood, LINE MAN, ShopeeFood, Robinhood) และหน้าร้าน
ช่วยคำนวณ **ต้นทุนต่อเมนู**, หัก **GP + VAT**, **ส่วนลด**, **ค่าโฆษณารายวัน** และสรุป **กำไร/ขาดทุน** ให้อัตโนมัติ

## วิธีใช้งาน

ไม่ต้องติดตั้งอะไร: **ดับเบิลคลิกเปิดไฟล์ `index.html`** ในเบราว์เซอร์ (Chrome / Edge / Safari) ได้เลย ใช้ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ
หรือนำโฟลเดอร์นี้ไปโฮสต์บน GitHub Pages / Netlify เพื่อเปิดจากมือถือ

> ครั้งแรกลองกด **"ทดลองด้วยข้อมูลตัวอย่าง"** ในหน้าภาพรวม เพื่อดูการทำงานทั้งหมดได้ทันที

ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage) ควร **ดาวน์โหลดไฟล์สำรอง** จากหน้าตั้งค่าเป็นประจำ และใช้ไฟล์นี้ย้ายข้อมูลไปเครื่องอื่นได้

## โมดูล

| หน้า | ทำอะไรได้ |
|---|---|
| 📊 **ภาพรวม** | ยอดขาย/กำไรวันนี้และเดือนนี้, กราฟ 14 วัน, จุดคุ้มทุน (ต้องขายกี่ออเดอร์/วัน), แจ้งเตือนสต็อกใกล้หมด, เมนูที่ขาดทุน, Food cost เกินเป้า |
| 🧾 **รับออเดอร์** | หน้าจอแบบ POS: เลือกช่องทาง → แตะเมนู → ใส่ส่วนลด (บาท/%) ระบุว่า **ร้านออก** หรือ **แอพออก** → เห็นกำไรบิลนั้นทันที, ประวัติออเดอร์ แก้ไข/ลบ, ส่งออก CSV |
| 🍛 **เมนู & ต้นทุน** | เลือกวัตถุดิบ (ปริมาณต่อจาน) และค่าใช้จ่าย (แพ็กเกจ, ค่าแรง, ค่าไฟ ฯลฯ) ที่ประกอบเป็น 1 เมนู, ตั้งราคาแยกตามช่องทาง, ดูกำไร/จานหลังหัก GP ทุกช่องทาง, **ราคาแนะนำ** ตามเป้ากำไร |
| 🥬 **วัตถุดิบ & สต็อก** | ราคาซื้อ, ขนาดบรรจุ, **% ใช้ได้จริง (Yield)** หลังตัดแต่ง → ต้นทุนต่อกรัม/ชิ้น, บันทึกการซื้อ (อัปเดตราคาล่าสุด + เพิ่มสต็อก), ตัดสต็อกอัตโนมัติเมื่อขาย |
| 💡 **ค่าใช้จ่าย** | แบบ **ต่อหน่วย** (กล่อง ถุง ช้อน แก๊สต่อจาน) และแบบ **รายเดือน** (ค่าแรง ค่าเช่า ค่าไฟ ค่าน้ำ) ที่ปันส่วนเข้าเมนูตามจำนวนจานต่อเดือน |
| 📣 **ค่าโฆษณา** | บันทึกค่าโฆษณาต่อวันต่อช่องทาง (บันทึกหลายวันในครั้งเดียวได้), ดู % ค่าโฆษณาต่อยอดขาย และ ROAS |
| 📈 **กำไร/ขาดทุน** | งบกำไรขาดทุนตามช่วงวันที่, ข้อสังเกตอัตโนมัติ, แยกตามช่องทาง / เมนู / รายวัน, ส่งออก CSV, พิมพ์ |
| ⚙️ **ตั้งค่า** | ชื่อร้าน, เป้า Food cost และกำไร, ช่องทางขายและ % GP, สำรอง/กู้คืนข้อมูล, ธีมสว่าง/มืด |

## สูตรคำนวณหลัก

- **ต้นทุนวัตถุดิบต่อหน่วย** = ราคาซื้อ ÷ (ขนาดบรรจุ × % ใช้ได้จริง)
- **ค่าใช้จ่ายรายเดือนต่อจาน** = ค่าใช้จ่ายรายเดือน ÷ จำนวนจานที่คาดว่าขาย/เดือน
- **GP** = ฐาน GP × %GP × (1.07 ถ้าคิด VAT)
  - ฐาน GP = ยอดอาหารเต็ม (ถ้าตั้งว่า "คิด GP จากยอดก่อนหักส่วนลด") หรือ ยอดหลังหักส่วนลดที่ร้านออก
- **ร้านได้รับจริง** = ยอดอาหาร − ส่วนลดที่ร้านออก − GP (ส่วนลดที่แอพออกให้ไม่กระทบร้าน)
- **กำไรขั้นต้นต่อบิล** = ร้านได้รับจริง − ต้นทุนวัตถุดิบและแพ็กเกจ − ค่าใช้จ่ายเพิ่มของบิล
- **กำไรสุทธิ** = กำไรขั้นต้น − ค่าโฆษณา − ค่าใช้จ่ายคงที่ (รายเดือน × 12 ÷ 365 × จำนวนวัน)

ราคาและต้นทุนของแต่ละออเดอร์ถูกบันทึกไว้ ณ ตอนขาย ดังนั้นการแก้ราคาวัตถุดิบหรือ % GP ภายหลังจะไม่ทำให้ตัวเลขของออเดอร์เก่าเปลี่ยน

```
js/app.js       หน้าจอของแต่ละโมดูล
js/demo.js      ข้อมูลตัวอย่าง
```
