# คู่มือตั้งค่าใช้งานหลายเครื่อง (Firebase)

ทำครั้งเดียวโดย **เจ้าของร้าน** ใช้เวลาประมาณ 15 นาที หลังจากนั้นทุกเครื่อง (มือถือ คอมพิวเตอร์ แท็บเล็ต) และพนักงานทุกคนจะเห็นข้อมูลร้านชุดเดียวกันแบบเรียลไทม์

- **ค่าใช้จ่าย:** ฟรี (แพ็กเกจ Spark ของ Firebase) เพียงพอสำหรับร้านขนาดเล็ก–กลาง ไม่ต้องผูกบัตรเครดิต
- **เน็ตหลุด:** ยังรับออเดอร์ได้ ระบบจะซิงก์ให้เองเมื่อกลับมาออนไลน์
- **ความปลอดภัย:** เฉพาะอีเมลที่เจ้าของร้านอนุญาตเท่านั้นที่เห็นข้อมูล

---

## ส่วนที่ 1: นำแอปขึ้นเว็บ (เพื่อเปิดจากมือถือได้)

1. เปิด https://github.com/Dreamizc/mine แล้วไปที่ **Settings → Pages**
2. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
3. Branch เลือก `claude/food-delivery-management-system-mndd1a` และโฟลเดอร์ `/ (root)` → กด **Save**
4. รอ 1–2 นาที แอปจะอยู่ที่ **https://dreamizc.github.io/mine/**

> repo นี้เป็นสาธารณะ แต่ **ข้อมูลร้านไม่ได้อยู่ใน repo** ข้อมูลอยู่ใน Firebase ของคุณ และเปิดดูได้เฉพาะคนที่ล็อกอินและได้รับอนุญาต

---

## ส่วนที่ 2: สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com ด้วยบัญชี Google ของร้าน
2. กด **Create a project** (สร้างโปรเจกต์) → ตั้งชื่อ เช่น `my-shop` → Google Analytics ปิดได้ → **Create project**

### 2.1 เปิดการเข้าสู่ระบบด้วยอีเมล
1. เมนูซ้าย **Build → Authentication** → กด **Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิด **Enable** (ตัวแรก) → **Save**

### 2.2 สร้างฐานข้อมูล
1. เมนูซ้าย **Build → Firestore Database** → กด **Create database**
2. Location เลือก **asia-southeast1 (Singapore)** (ใกล้ไทย เร็วที่สุด)
3. เลือก **Start in production mode** → **Create**

### 2.3 คัดลอกค่าตั้งค่า (firebaseConfig)
1. กดรูปเฟือง ⚙️ ข้างคำว่า Project Overview → **Project settings**
2. เลื่อนลงไปหัวข้อ **Your apps** → กดไอคอน **`</>`** (Web)
3. ตั้งชื่อแอป เช่น `shop-web` (ไม่ต้องติ๊ก Hosting) → **Register app**
4. จะเห็นโค้ดหน้าตาแบบนี้ → **คัดลอกส่วน `const firebaseConfig = { ... };` ทั้งก้อน**

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "my-shop.firebaseapp.com",
  projectId: "my-shop",
  storageBucket: "my-shop.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

## ส่วนที่ 3: เชื่อมต่อแอป (เจ้าของร้าน)

1. เปิดแอป (https://dreamizc.github.io/mine/) → หน้า **ตั้งค่า** → การ์ด **☁️ ใช้งานหลายเครื่อง**
2. วาง firebaseConfig ที่คัดลอกมา → กด **เชื่อมต่อ**
3. กรอกอีเมล + รหัสผ่าน (อย่างน้อย 6 ตัว) → กด **สมัครบัญชีใหม่**
4. เปิดอีเมล กดลิงก์ยืนยัน (ถ้าไม่เจอ ดูในโฟลเดอร์ Spam) → กลับมากด **ฉันยืนยันอีเมลแล้ว**
5. แอปจะแสดง **"บัญชีนี้ยังเข้าถึงข้อมูลร้านไม่ได้"** พร้อมกฎความปลอดภัย (ใส่อีเมลของคุณไว้ให้แล้ว) — นี่เป็นเรื่องปกติของครั้งแรก
   1. กด **คัดลอกกฎ**
   2. Firebase Console → **Firestore Database → แท็บ Rules** → ลบของเดิมทั้งหมด → วางกฎ → **Publish**
   3. รอ 1 นาที แล้วกลับมากด **ลองใหม่**
6. เลือกวิธีเริ่มต้น: **อัปโหลดข้อมูลจากเครื่องนี้** (ถ้าเคยใช้แอปในเครื่องนี้มาก่อน) หรือ **เริ่มต้นใหม่**

เสร็จแล้ว! มุมซ้ายบนจะขึ้น 🟢 **ออนไลน์ · อีเมลของคุณ**

## ส่วนที่ 4: เพิ่มเครื่องอื่น และเพิ่มพนักงาน

**เพิ่มเครื่องของตัวเอง (เช่น มือถือ)**
1. ในเครื่องที่เชื่อมต่อแล้ว: ตั้งค่า → **คัดลอกลิงก์เชื่อมต่อ** → ส่งลิงก์ไปที่มือถือ (เช่น ส่ง LINE หาตัวเอง)
2. เปิดลิงก์ในมือถือ → เข้าสู่ระบบด้วยอีเมลเดิม
3. (แนะนำ) กด "เพิ่มไปยังหน้าจอโฮม" ในเบราว์เซอร์มือถือ จะได้เปิดเหมือนแอป

**เพิ่มพนักงาน**
1. เจ้าของร้าน: ตั้งค่า → **พนักงานที่เข้าใช้ได้** → พิมพ์อีเมลพนักงาน → **เพิ่ม**
2. ส่งลิงก์เชื่อมต่อให้พนักงาน → พนักงานกด **สมัครบัญชีใหม่** ด้วยอีเมลนั้น → ยืนยันอีเมล → ใช้งานได้

| | เจ้าของร้าน | พนักงาน |
|---|:-:|:-:|
| รับออเดอร์ / ดูประวัติ | ✅ | ✅ |
| แก้เมนู วัตถุดิบ ค่าใช้จ่าย ค่าโฆษณา | ✅ | ✅ |
| ดูรายงานกำไร/ขาดทุน | ✅ | ✅ |
| แก้ข้อมูลร้าน เป้าหมาย % GP ช่องทางขาย | ✅ | ❌ |
| เพิ่ม/นำพนักงานออก | ✅ | ❌ |

ออเดอร์ทุกบิลจะบันทึกว่าใครเป็นคนรับ (แสดงในประวัติออเดอร์)
พนักงานลาออก: กด **นำออก** แล้วบัญชีนั้นจะเข้าดูข้อมูลไม่ได้ทันที

## คำถามที่พบบ่อย

**ฟรีจริงไหม?** แพ็กเกจฟรีอ่านได้ 50,000 ครั้ง/วัน เขียนได้ 20,000 ครั้ง/วัน การเปิดแอป 1 ครั้งจะอ่านออเดอร์ย้อนหลังตามจำนวนวันที่ตั้งไว้ (ค่าเริ่มต้น 90 วัน) ร้านที่ขายวันละ 30–50 บิลและเปิดแอปจากไม่กี่เครื่องจะอยู่ในโควตาฟรี ถ้าร้านใหญ่ขึ้น ลดจำนวนวันในหน้าตั้งค่าได้ หรืออัปเกรดเป็นแพ็กเกจ Blaze (จ่ายตามใช้ ประมาณ 2 บาทต่อการอ่าน 100,000 ครั้ง)

**ข้อมูลเก่ากว่า 90 วันหายไหม?** ไม่หาย ยังอยู่บน Firebase แค่ไม่โหลดมาแสดง ถ้าต้องการดูรายงานย้อนหลังนานกว่านั้น เพิ่มจำนวนวันในหน้าตั้งค่า

**ลืมรหัสผ่าน?** หน้าเข้าสู่ระบบ → กรอกอีเมล → กด **ลืมรหัสผ่าน** → ตั้งรหัสใหม่จากลิงก์ในอีเมล

**อยากเลิกใช้ออนไลน์?** ตั้งค่า → **เลิกใช้ออนไลน์ในเครื่องนี้** ข้อมูลล่าสุดจะเก็บไว้ในเครื่องนั้น และข้อมูลบน Firebase ไม่ถูกลบ

**เปลี่ยนเจ้าของร้าน / ใช้อีเมลเจ้าของใหม่?** ต้องแก้อีเมลในกฎความปลอดภัย (Firestore → Rules) และแก้ช่อง `ownerEmail` ในเอกสาร `config/main` ใน Firestore
